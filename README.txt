iStore Attingal — Nexshaly Studio demo
======================================

This is an unofficial website concept based on the shop sign photo supplied by the prospective client.
It is not the store's official website.

PREVIEW
1. Extract the ZIP.
2. Open index.html in Chrome, Edge or Firefox.
3. Internet connection is needed for the Google Fonts. The rest of the site works locally.

PUBLISH WITH GITHUB PAGES
1. Create a NEW public repository, e.g. istore-attingal-demo.
2. Upload index.html, style.css, script.js and the assets folder to the repository root.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Wait for GitHub Pages to publish.

BEFORE CLIENT LAUNCH
- Confirm the exact business name, address, phone and opening hours.
- Confirm which Apple products and other brands are actually sold.
- Replace the illustrative product catalogue with real store-approved photos and names.
- Confirm the telephone number and WhatsApp number with the owner.
- Add the owner's Instagram profile and selected public Reel embeds only after permission.
- Confirm all promotional offers, terms and expiry dates with the owner.
- Confirm whether the shop is authorised to make any Apple reseller claims; this demo does not make that claim.
- Obtain permission before using customer reviews, logos or photos.
- Remove the "UNOFFICIAL WEBSITE CONCEPT" label only after approval and handover.

PRODUCTS
Edit the `products` array in script.js to change product names, categories, and descriptions.
Current products are illustrative category placeholders, not confirmed stock.

CONTACT
The call link currently uses the number supplied in the prospect details: +91 73995 55333.
Verify it with the owner before publishing. No WhatsApp link is activated in this concept.

This is a static HTML/CSS/JS concept. It has no admin dashboard, online checkout, stock database,
or self-service offer management. Those can be scoped as separate development features.

REVISION: The shop sign photo is not used. It was visual inspiration only. The contact section now contains original CSS-based abstract showroom artwork.
